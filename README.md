# Blendery

Blendery는 카페 매장에서 아날로그 방식으로 관리되던 음료 레시피를 디지털화하여  
바리스타가 레시피를 빠르게 탐색하고, 주문 대응 시간을 줄일 수 있도록 돕는  
카페 전용 레시피 관리 및 검색 서비스입니다.

---

## 1. 서비스 개요

카페 매장에서는 메뉴가 많고 옵션이 다양해질수록  
레시피 탐색 과정에서 불필요한 시간 지연이 발생합니다.

Blendery는 이 문제를 해결하기 위해 다음을 목표로 합니다.

- 레시피를 **Variant 단위로 구조화**
- 검색 및 즐겨찾기를 통한 **즉각적인 접근**
- 점주와 스태프의 **역할 분리 기반 관리**

## 3. 주요 기능

### 🔹 레시피 관리
- 카페별 음료 레시피 관리
- HOT / ICE, 사이즈 등 옵션별 Variant 분리

### 🔹 레시피 검색
- 메뉴명 기반 검색
- 초성 및 prefix 기반 빠른 탐색

### 🔹 즐겨찾기
- 자주 사용하는 레시피 Variant를 즐겨찾기로 등록
- 반복 주문 상황에서 즉시 접근 가능

### 🔹 권한 구조
- 점주(Owner) / 스태프(Staff) 역할 분리
- 역할에 따른 접근 권한 제어
